**取证分级**（v2 最重要的一栏）：

- **A 你明说**：你的原话直接要求。
- **B 你确认**：我提的方案，你回「确实 / 可以 / 嗯」。
- **C 我推断**：你没说过，但从你的话里推得出来，**未经你确认**。
- **D 我发明**：与你的话无关。

v1 把若干 C 当成 A 引用了——最典型的是「事实卡归中间层维护」：那是**我表格里的话**，你的原话里只有「自动压缩成小的一个事实」。v2 全部降级重标。
